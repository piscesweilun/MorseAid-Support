# MorseAid Support

MorseAid 災訊的官方支援與隱私網站。本目錄是公開網站的本地原始碼，對外發布至：

- 儲存庫：https://github.com/piscesweilun/MorseAid-Support
- 首頁：https://piscesweilun.github.io/MorseAid-Support/
- 支援：https://piscesweilun.github.io/MorseAid-Support/support.html
- 隱私：https://piscesweilun.github.io/MorseAid-Support/privacy.html

網站不使用 Cookie、分析、廣告、追蹤像素、第三方字型或第三方腳本。

## 修改與發布

1. 在本目錄修改並預覽靜態網站。
2. 將本目錄的所有內容（包含 `.github`）同步至公開儲存庫根目錄。
3. 提交並推送公開儲存庫的 `main` 分支。
4. 等待 `Deploy support site to GitHub Pages` 工作流程成功。
5. 以公開瀏覽器重新驗證首頁、支援頁、隱私頁及支援問題入口。

主專案與公開儲存庫應使用相同的網站內容；修改正式網址或資料處理說明時，也要同步更新 `Docs/` 內的上架及隱私文件。
